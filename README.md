# Momentum Todo

Premium-style todo app built with Vite + React.

## Features
- Add task
- Edit task
- Trash bin instead of direct delete
- Restore from trash
- Clear trash
- Search + filters
- Priority, category, due date
- Progress ring
- Dark / light mode
- localStorage autosave

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
You can deploy the `dist` folder to services like Netlify, Vercel, Firebase Hosting, or GitHub Pages.
